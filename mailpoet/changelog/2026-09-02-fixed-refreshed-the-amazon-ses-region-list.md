# Type: Fixed

# Description

The Amazon SES region list in Settings is up to date again. Seven regions AWS has added since 2022 are now available: Hyderabad, Malaysia, Calgary, Zurich, Tel Aviv, UAE and GovCloud (US-East). China (Ningxia) now works, because MailPoet sends those requests to the right AWS domain. Hong Kong and China (Beijing) have been removed, as Amazon SES does not run in either.
